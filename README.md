## Repository structure

This is a static website built with HTML, CSS, vanilla JavaScript and Jekyll SEO/sitemap plugins. The default branch is `main`.

- `assets/site.css` — shared styling and responsive layout.
- `assets/site.js` — navigation, slideshow and form interactions.
- `assets/product-detail.js` — product detail data and rendering.
- `assets/272.jpg` — website logo.
- `worker/` — retired Cloudflare Worker endpoint; it returns HTTP 410 and is not used for form delivery.
- `ai-worker/` — website assistant code and configuration.

## Forms and enquiries

The general contact form and website issue form use FormSubmit. Form delivery depends on the receiving mailbox and endpoint activation. The email workflow should be tested periodically by an authorized mailbox owner.

## Website maintenance

The website is maintained through the repository's `main` branch and deployed through its configured hosting workflow. After a content or metadata change, check the deployment workflow and inspect the live pages.
